## Overview

AI Security Trainer helps learners develop usable cybersecurity skills through active practice instead of reading alone. Lessons, quizzes, and challenge-based activities are combined into a structured experience that encourages users to apply what they learn.

Learning is organized around ongoing progress, measurable milestones, and scenario-driven exercises. The platform can support independent study, instructional settings, and anyone seeking a guided approach to information security topics with built-in feedback and progression.

## Using the Platform

Once the application is running, open its web interface and create a profile or sign in to an existing one. You can then work through lessons and quizzes while using the skills map to identify and extend your cybersecurity topic coverage.

A common learning sequence is:

1. Create a profile or sign in
2. Add an avatar, if preferred
3. Select and begin an interactive lesson
4. Work through the related quizzes and scenarios
5. Check XP, badges, dashboard statistics, and leaderboard standing
6. Use the skills map and progress views to follow development over time

AI Security Trainer is designed for repeated practice, allowing users to return for additional activities and continue following their learning path.
